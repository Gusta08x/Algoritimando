# Algoritimando

GDD

EXPERIÊNCIA -

Emoções que quero provocar:
Estratégia • Curiosidade • Criatividade • Desafio • Descoberta • Reflexão

Frase da Experiência:
Quando alguém jogar o nosso jogo, vai sentir um despertar da reflexão sobre o próprio cotidiano, porque o trabalho com situações do dia a dia geram um reconhecimento da própria rotina e facilita o entendimento dos algoritmos e lógica computacional.

TEMA E CONCEITO -

Tema:
Lógica computacional / Algoritmos / Passo a passo

Conceito:
O agente precisa organizar a ordem das ações para que uma situação cotidiana requisitada pré-definida ou personalizada seja finalizada corretamente.

HISTÓRIA E MISSÃO -

História:
Algoritimando acontece no mundo atual. Diferentes situações ocorrem simultaneamente em diversos contextos e precisam de uma ordem específica para serem finalizadas com êxito. Agentes de uma empresa mundial ultra tecnológica responsável por resolver problemas cotidianos precisam entrar em ação. Após serem convocados pelo robô guia, o agente desloca-se para a localização de cada cliente para buscar a solução.

Missão + como se vence:
Ajude o cliente a resolver o problema. Encaixe os cards em uma das ordens corretas para que a ação seja realizada com êxito. A cada acerto, o agente é recompensado com estrelas e dicas. Caso o objetivo falhe, será impossível continuar até que o erro seja corrigido de acordo com o robô que guiará a situação.
